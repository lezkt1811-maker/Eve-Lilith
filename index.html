WHAT THIS RANT IS ACTUALLY ARGUING

Tropical astrology uses a twelve-part seasonal zodiac anchored to the equinoxes and solstices. Astronomical constellations are irregular regions of the sky. The Sun's apparent annual path crosses the astronomical constellation Ophiuchus as well as the traditional twelve zodiac constellations. A 13-sign constellation-based astrology system uses those astronomical regions as an alternative astrological framework.

Astrology itself is not established as a scientific method for predicting personality or events. This project explores a constellation-based astrological philosophy and creative mythology.

FREE LOCAL VIDEO OPTIONS

This page is the control panel, script editor, preview studio, and prompt generator. It does not itself produce a finished talking-head video. For that, you could optionally use separate free/local tools:

• LivePortrait — portrait animation from a still image
• SadTalker — talking-head animation driven by audio
• Piper — offline text-to-speech
• Coqui TTS — offline text-to-speech, if compatible with your system
• FFmpeg — final video/audio assembly
• MoviePy — optional Python-based assembly route
• OBS — simple screen-recording fallback for capturing this preview

These tools are entirely optional. This page opens and works fully without them.
